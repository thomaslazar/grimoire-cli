# Byte-Passthrough Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop deserializing API responses into hand-written DTOs just to re-serialize them for stdout — print the server's bytes instead, and delete `src/GrimoireCli/Models/`.

**Architecture:** PR 2 of [the design](../specs/2026-08-19-edge-client-and-byte-passthrough-design.md). Services return the raw response string; commands print it through the existing `ConsoleOutput.WriteRawJson`. The DTOs' three jobs are re-homed: printing becomes passthrough, the six exit-code readers use raw-JSON field helpers, and `--help` response samples come from the generated Kiota models that PR 1 made available. A JSON-validity guard moves into `GrimoireApiClient.SendAsync` to preserve the HTML-catch-all detection the DTOs were incidentally providing.

**Tech Stack:** .NET 10, System.CommandLine 2.0.7, System.Text.Json source generation, Kiota-generated models.

## Global Constraints

- **Branch:** `feat/byte-passthrough`, off `main`. PR targets `main`.
- **Never hand-edit `src/GrimoireCli/Generated/`.** It is regenerated only by `bash tools/generate-api-client.sh`.
- **Generated example files are regenerated, never hand-edited** — `src/GrimoireCli/Commands/RequestExamples.g.cs` and any successor. Drift tests shell out to the generator and compare.
- **The local stack is the digest-pinned edge build.** `docker compose -f docker/docker-compose.yml up -d --wait`, then `bash docker/seed.sh`. Both scripts default to `http://host.docker.internal:9481`; no `GRIMOIRE_SERVER` override is needed.
- **`bash docker/smoke-test.sh` against that stack is the gate.**
- **stdout stays valid JSON**; logs and human-facing lines go to stderr.
- **`AppJsonContext` keeps `WriteIndented = true`.** It exists for config-file readability and, once the response DTOs are gone, that is all it serves. Response output must not depend on it.
- **Conventional Commits**, imperative, lowercase, no period, no `Co-Authored-By`, no tool attribution.
- **`CHANGELOG.md` is not touched** — it belongs to the release process.
- **`docs/grimoire-api-coverage.md` is not touched** — which endpoints are called does not change. It is generated by `tools/generate-api-coverage.py` anyway.
- **Run `dotnet format GrimoireCli.sln` after modifying any C# file**, and keep method bodies free of the blank-line patterns `.editorconfig` and CLAUDE.md forbid.

```csharp
    /// <summary>
    /// Whether a top-level array property has at least one element. The bulk
    /// endpoints report per-item failures this way, and the exit code turns on
    /// nothing else about them.
    /// </summary>
    internal static bool HasItems(string json, string property)
    {
        try
        {
            using var doc = JsonDocument.Parse(json);
            return doc.RootElement.TryGetProperty(property, out var el)
                   && el.ValueKind == JsonValueKind.Array
                   && el.GetArrayLength() > 0;
        }
        catch (JsonException)
        {
            return false;
        }
    }

    /// <summary>
    /// Whether a body is JSON, or empty. A 204 or other bodiless success is
    /// legitimate and parses as nothing. Pure so both branches are testable —
    /// <see cref="EnsureJson"/> cannot be, because it exits.
    /// </summary>
    internal static bool IsJsonOrEmpty(string json)
    {
        if (string.IsNullOrWhiteSpace(json)) return true;
        try
        {
            using var doc = JsonDocument.Parse(json);
            return true;
        }
        catch (JsonException)
        {
            return false;
        }
    }

    /// <summary>
    /// Fails a response body that is not JSON, taking over the check the response
    /// DTOs used to provide as a side effect of deserializing. Grimoire's SPA
    /// catch-all answers an unroutable request (an empty, ".", or otherwise
    /// mis-encoded id) with an HTML 200, and without this that page would reach
    /// stdout as though it were the API's answer.
    /// </summary>
    internal static void EnsureJson(string json, string endpoint)
    {
        if (IsJsonOrEmpty(json)) return;
        _logger.Debug($"unparseable body from {endpoint}: {TruncateForLogging(json)}");
        _logger.Error($"Response from {endpoint} could not be parsed as JSON. Run with --debug to see the response body.");
        Environment.Exit(2);
    }
```

- [ ] **Step 8: Implement `Pretty`**

In `src/GrimoireCli/Output/ConsoleOutput.cs`, replace `WriteRawJson`:

```csharp
    /// <summary>
    /// Set from the root --pretty option. Off means the server's bytes reach
    /// stdout unchanged, which keeps undeclared fields, explicit nulls and the
    /// server's key order.
    /// </summary>
    public static bool Pretty { get; set; }

    /// <summary>
    /// Writes a response body. Verbatim by default; re-indented under --pretty,
    /// which costs a parse and re-serialize, so the bytes are no longer the
    /// server's. A body that does not parse is passed through untouched rather
    /// than swallowed — GrimoireApiClient.EnsureJson is what rejects those, and
    /// this must not become a second, quieter place that decides.
    /// </summary>
    public static void WriteRawJson(string json)
    {
        if (!Pretty)
        {
            Console.Out.WriteLine(json);
            return;
        }
        try
        {
            using var doc = JsonDocument.Parse(json);
            Console.Out.WriteLine(JsonSerializer.Serialize(doc.RootElement, PrettyOptions));
        }
        catch (JsonException)
        {
            Console.Out.WriteLine(json);
        }
    }

    private static readonly JsonSerializerOptions PrettyOptions = new() { WriteIndented = true };
```

`JsonSerializer.Serialize(JsonElement, JsonSerializerOptions)` is reflection-free
for `JsonElement`, so this stays AOT-safe; `self-test` covers it in Task 7.

## Notes for the implementer

- **`ConsoleOutput.Pretty` is static mutable state**, set once from `Program.cs`. Tests must save and restore it, as the Task 1 tests do, or they leak into each other.
- **Do not reintroduce a DTO to make a test easier.** If a test needs a field, parse the JSON.
- **`permissionHint` must keep agreeing with each command's role tag** — CLAUDE.md requires tag `admin` ↔ hint "the admin role" and tag `gm or admin` ↔ hint "the gm or admin role". The conversions touch these lines; do not drop or reword them.
- **`SendStreamAsync` and the binary commands are out of scope.** `books thumbnail` and `systems cover get` return bytes, not JSON.
- **Writes go to the local digest-pinned stack, never the live instance.** The smoke test writes only to `Shadowrun 4 DE`; `seed.sh` deliberately leaves it unpatched as a metadata fixture.
